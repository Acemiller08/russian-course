# Курс русского · DLI Russian Basic Course practice

An installable web app for practicing the DLI Russian Basic Course, Lessons 1–41:
a diagnostic, daily spaced-repetition practice, Grind drills, per-lesson vocabulary study,
and Names & Numbers.

**Open it:** https://acemiller08.github.io/russian-course/

- **iPhone / iPad:** open the link in Safari → Share → Add to Home Screen.
- **Android:** open the link in Chrome → ⋮ → Install app.
- Works offline after the first visit. Progress is saved on your own device only;
  use Results → Download backup to move it.
